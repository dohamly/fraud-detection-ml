# fraud-detection-ml
Machine learning project for online payment fraud detection using Python and scikit-learn. Includes data preprocessing, class imbalance handling with SMOTE, and evaluation using F1-score and ROC-AUC.
## Models used
- Logistic Regression
- Random Forest
- Gradient Boosting

## Techniques
- SMOTE for class imbalance handling
- Train/test split for model evaluation
- Metrics: Accuracy, Precision, Recall, F1-score, ROC-AUC
